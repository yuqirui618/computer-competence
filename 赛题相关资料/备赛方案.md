# 胸片分类备赛方案

赛题边界和提交要求以[赛题原件](README.md)为准。当前数据审计和加载已验收，真实模型分数、正式 T4 延迟和推理包大小待实测。[数据验收日志](../dataset/logs/test_20261103_1705.md)

## 单模型起点

- 主候选为 MambaOut-Tiny。已核对 `timm/mambaout_tiny.in1k` 的 ImageNet-1K 来源、Apache-2.0 许可、公开访问及固定版本权重 SHA-256。保留名称、许可、来源、哈希及上游数据说明用于申报。[权重记录](weight_metadata.json)
- 先用 ConvNeXt-Tiny 加 BCE 建立对照。两者使用 10 个独立 logits，训练用 `BCEWithLogitsLoss`，推理用 Sigmoid。固定训练预算、预处理和划分后比较骨干。
- 先逐图预测，再对同一 Study 的各类概率取均值。一个 Subject 的不同检查分别输出。逐图沿用检查级标签作为基线，后续可比较聚合后再计算训练损失。

## 实验顺序

| 顺序 | 对照 | 记录 |
| --- | --- | --- |
| 1 | ConvNeXt-Tiny 与 MambaOut-Tiny，均使用 BCE | Study 级 macro AUC、macro F1、逐类指标 |
| 2 | BCE、ASL 与 RGB Loss | 低频类收益、真实 batch、训练稳定性 |
| 3 | 概率均值与 logit 均值，224/288 与 320/384 输入 | 验证集收益、端到端延迟和推理包大小 |
| 4 | 可选 DINOv2 Small、固定 TTA 或集成 | 验证收益及是否满足部署预算 |

ASL 与 RGB Loss 按所用实现保留出处与许可。类别统计取自官方训练集。RGB Loss 在小 batch 下需验证低频类参考样本的覆盖。[ASL 实现](https://github.com/Alibaba-MIIL/ASL) · [RGB Loss 实现](https://github.com/xup6YJ/RGB-Loss)

## 部署与交付

验证集用于选模型、聚合与阈值。确定最终方案后冻结预处理、权重及阈值。用正式 T4 环境测读图至写出结果的端到端耗时，并核对推理所需文件总大小与最终 CSV。评估脚本和成本测试应复用同一推理逻辑。每轮记录种子、代码版本、权重哈希、图像尺寸、真实与有效 batch、聚合、指标、耗时及文件大小。[正式规则和补充说明](README.md)
