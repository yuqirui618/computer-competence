# 官方比赛数据获取与接收

状态日期：2026-11-02。**官方数据尚未下载。** 已检查公开赛题页和考生入口，公开页没有列出可直接下载的比赛数据包地址；考生入口显示 QQ 登录。尚未读取登录后的数据下载区域。

## 1. 需要从官方账号获取的信息

打开 [官方考生入口](https://www.ncccu.org.cn/index/Login/login.html)，使用自己的参赛账号完成 QQ 登录。在账户中查看人工智能赛项的数据下载材料；实际后台栏目名称以页面为准，本次未核实。

取得以下任一项后即可继续：

- 官方后台提供的数据下载地址，以及必要的提取码/压缩包密码和分卷清单；
- 已下载压缩包的完整本地路径。

不用发送账号密码或浏览器 Cookie。QQ/比赛账号登录与此前 GitHub 上传认证相互独立。若后台没有数据入口，应先查看参赛资格和官方通知，不猜测未公开文件地址，也不使用来源不明的镜像。

## 2. 已准备的本地目录

```text
data/official/
  downloads/   原始压缩包或分卷，保留原文件名
  raw/         核对压缩包清单后解压的数据
  manifests/   下载记录、文件哈希、私有数据核查结果
```

完整根路径：`C:\Users\asus\Desktop\计算机能力挑战赛\data\official\`。

`data/` 整体已被 Git 忽略。受限下载链接、提取码、官方标签、患者/检查标识及实际预测只保存在这个本地目录，不写入公开资料。

## 3. 下载到达后进行的检查

1. 核实链接确实来自官方后台，读取文件大小并检查本地空间；需要时使用断点续传，保留分卷。
2. 检查下载后的长度、发布方校验值（若提供）、压缩包完整性，记录 SHA-256。
3. 先列出压缩包清单，再在 `raw/` 内安全解压；保留官方原始目录及划分。
4. 对照实际文件核查训练/验证/测试的检查数、图片数、标签结构、10 类映射、图像与 Study 对应关系；检查数不能当成图片数。
5. 在官方训练/验证数据上检查患者重叠、损坏图片、缺失标签和重复图片；测试仅检查提交所必需的清单、格式及推理运行，不拟合其统计量或反向调参。
6. 读取官方提交模板，确认列名、类型、ID 前导零和每 Study 的 10 类覆盖。

官网公布的预期检查数为训练 `18513`、验证 `859`、测试 `1414`。[来源](https://www.ncccu.org.cn/index/Paper/case1.html)。实际拿到的版本若不同，先核对是否为不同阶段或新版数据，不自行修改到预期数量。

准备目录和下载公开模型权重都不代表已取得比赛数据。收到官方数据后再更新私有接收记录和数据状态。
