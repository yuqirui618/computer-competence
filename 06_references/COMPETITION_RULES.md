## 2. 训练与推理边界

| 定位 | 对本项目的直接影响 |
| --- | --- |
| 规则第 1–2 条；补充第二、五节 | 仅选非医学、可公开获取并可再分发的预训练；排除 NC、gated 和外部医学知识权重/数据 |
| 补充第三节 | 可蒸馏，但教师和学生的来源都须合规；不推理的教师不计最终部署大小，仍需申报 |
| 补充第四节 | 允许仅用官方训练图像做自监督预训练；不得混入测试或外部医学数据 |
| 规则第 3 条 | 验证集可在选择结束后并入训练；并入后不再承担选模/调参用途 |
| 规则第 5–6 条；补充第六至八节 | 测试只做固定前向；禁止梯度更新、统计量重估或拟合；固定 TTA/集成与确定性聚合可评估使用 |
| 官网第八部分 | 比赛数据未经允许不得传播；2026-11-03仓库所有者确认获得原始影像及3份CSV公开下载授权，依此通过Release发布；实际预测及下载凭据不发布 |

## 3. 部署与材料

规则第 7–8 条规定单图端到端平均 ≤100ms、实际推理必要文件解压后总和 ≤500MB。按指定 100 图、batch=1、3 轮及 5 图预热计时，包含读写和前后处理。不能只计 GPU 前向。

补充第九节解释超时处置和结果一致性：cost.py 需调用与 predict.py 相同逻辑，排序和二值判定一致；概率容差为 1e-3。保留加速前后逐样本核对。具体复测分档以附件原文执行，不能把“可整改”当作可以放宽开发目标。

按规则附录 A 提前备齐代码、推理模型、cost.py、预训练来源/许可证/数据说明/哈希、数据声明与 submission.csv。网页提到初赛预测 CSV，不能据此忽略附录的核验材料要求；具体上传入口以报名系统通知核对。完整核验材料在截止前准备好。

## 4. 对方案的结论

当前采用“通用视觉权重 + 官方胸片微调”。MambaOut ImageNet-1K 是优先核验对象；DINOv3 gated 获取、MedCLIPSeg 医学/NC、ConvNeXt V2 和 MambaVision 的 NC 权重排除。最新医学论文可借鉴方法，但其外部医学权重、标注或默认脚本不能直接带入比赛。
