# 顶刊三模型：文献核查与赛题适配

核查日期：2026-11-05。本轮冻结三个候选：**CAFormer-S18、DenseNet-121、HRNet-W18**。入选依据是已正式发表于 IEEE Transactions on Pattern Analysis and Machine Intelligence（TPAMI）的架构论文、现有环境可用的分类实现，以及来源明确的自然图像预训练权重。这里是通用视觉骨干迁移到本题，并不是下载了三份可直接参赛的胸片专用成品模型。此文件写于训练前，不填写未完成的实验分数。

本题是10类胸片多标签分类，按同次检查（Study）汇总各图概率。每个候选从各自公开的ImageNet-1K权重开始，用全部30,344张官方训练图适配5轮，完整验证1,422图、859次检查、228患者；单GPU按顺序运行。主要比较Study Macro AUC，F1采用相同患者分折选阈值口径。现有最高AUC候选为MambaOut Gamma/轻噪声模型0.8021774782，原保留单模型为0.8019769551。基线数值来自本机已完成记录，不是新模型结果。

## 为什么选择这三种结构

**CAFormer-S18**在前部采用卷积混合局部信息，在后部采用自注意力整合上下文，提供与MambaOut门控卷积不同的结构对照。模型卡为作者训练的ImageNet-1K权重，约26.3M参数、224输入、Apache-2.0。[作者代码](https://github.com/sail-sg/metaformer)和[作者期刊稿](https://arxiv.org/pdf/2210.13452v4)均公开。局部与全局信息可能对胸片有帮助是待检验假设，ImageNet成绩不能保证本题提高。

**DenseNet-121**复用并拼接先前层特征，适合作为参数较少的稠密连接路线对照。本次采用Ross Wightman用RandAugment配方训练的ImageNet-1K权重，约8.0M参数，模型卡Apache-2.0；它不是任何NIH、CheXpert或MIMIC胸片训练后的CheXNet权重。[架构作者代码](https://github.com/liuzhuang13/DenseNet)及[期刊扩展作者稿](https://arxiv.org/pdf/2001.02394v1)可核查。原作者代码BSD-3-Clause和本次具体分发渠道的权重许可分开保留，不能把所有DenseNet权重都自动视为同一许可或训练来源。

**HRNet-W18**并行维护不同分辨率特征并反复融合，为胸片细小征象提供另一种结构假设。本次选作者ImageNet-1K分类权重的`ms_aug_in1k`渠道，约21.3M参数、224输入，模型卡MIT。[作者项目](https://jingdongwang2017.github.io/Projects/HRNet/)、[官方分类代码](https://github.com/HRNet/HRNet-Image-Classification)和[MIT许可](https://github.com/HRNet/HRNet-Image-Classification/blob/master/LICENSE)公开。这里选分类分支，不能下载姿态或分割checkpoint再当成胸片分类器。高分辨率特征保留并不等于从224输入恢复已经丢失的原图细节，也不能据此保证AUC提高。

## 直接能用的部分与必须适配的部分

可以复用的是公开骨干结构、ImageNet权重和现有timm接口。必须严格载入对应预训练文件后重置为10输出，训练时使用独立logits和多标签BCE，推理用Sigmoid；不能沿用1000类Softmax。各模型归一化按实际config.json，不凭名字猜测。训练读取既有512缓存并缩放到224，验证读取原图、固定预处理；同一Study各图概率取均值，与已有链一致。

三种结构的正则化参数含义不同，不能机械复制MambaOut的参数名并声称作用相同：本机timm的CAFormer实现有DropPath；HRNet没有执行DropPath，`drop_path_rate`落入额外配置不等于生效；本机timm 1.0.22中，DenseNet顶层`drop_rate`作用于分类头之前的Dropout，`proj_drop_rate`才传给每个DenseLayer；DenseLayer自身内部参数也叫drop_rate，不能混淆层级。当前候选采用head drop 0.2、dense-layer drop 0。实际建模/训练参数应以冻结plan和实现审阅为准。含BN的DenseNet与HRNet在验证时必须eval，验证前后核对running buffers不变，只让官方训练数据更新统计量。

这次是5轮、224、单个训练种子的候选初筛，不是完整复刻论文的大规模预训练。已有MambaOut经历过多次方案与轮次选择，而新模型预算较短；若未超过，只能说本次指定配置没有超过，不能宣布整个架构永久更差。已有验证集也被反复用于选择；最佳轮的置信区间不会自动消除选择偏差。正式T4端到端100ms与推理文件总计500MB仍需单独按赛事环境验收，参数较少不等于延迟已达标。

## 为什么没有直接套医学顶刊的现成胸片模型

赛题正式《参赛规则》和《参赛补充规则》允许公开可下载、可再分发的非医学领域预训练权重，例如ImageNet；外部医学影像预训练、NC和gated渠道不符合当前规则。用户对官方数据公开发布的授权，不等于豁免模型预训练来源规则。本轮使用通用自然图像初始化，再仅用官方训练集有监督适配；测试图像不参与训练、BN统计、先验或阈值选择。

| 医学顶刊方法 | 已核查的公开来源 | 本轮不能直接使用其成品checkpoint的原因 |
| --- | --- | --- |
| Ark+，Nature 643:488-498（2025），DOI 10.1038/s41586-025-09079-8 | [Nature原文](https://www.nature.com/articles/s41586-025-09079-8)、[官方代码](https://github.com/jlianglab/Ark)、[官方许可](https://github.com/jlianglab/Ark/blob/main/LICENSE) | 原权重汇集多个外部胸片数据集训练；官方许可还有noncommercial限制、权重申请流程。不能直接用它产生所谓合规参赛成绩。 |
| CheXFound，TMI 44(12):4787-4799（2025），DOI 10.1109/TMI.2025.3581907 | [出版记录](https://pubmed.ncbi.nlm.nih.gov/40549526/)、[官方代码](https://github.com/RPIDIAL/CheXFound) | 原权重在约987K外部胸片上预训练，代码MIT不能改变医学数据来源。GLoRI局部/全局分类头可借鉴，但新接到MambaOut并从头训练只能称适配版本，不能称原CheXFound复现。 |
| RAD-DINO，Nature Machine Intelligence（2025），DOI 10.1038/s42256-024-00965-w | [正式文章](https://doi.org/10.1038/s42256-024-00965-w)、[Microsoft官方模型卡](https://huggingface.co/microsoft/rad-dino) | 虽然模型卡MIT，公开权重在多个外部胸片集上预训练，仍不满足本赛非医学初始化限制。官方说明公开checkpoint也不同于论文使用私有数据的版本，不能把论文分数直接归给公开权重。 |

这些排除针对当前权重渠道或适配成本，不是说其方法无效；也没有用不合规则的权重试跑后冒充失败实验。

## 更贴近胸片的结构备选：WSRPN（本轮未试）

WSRPN的正式论文是 **Weakly Supervised Object Detection in Chest X-Rays With Differentiable ROI Proposal Networks and Soft ROI Pooling**，TMI 44(1):221-231（2025），DOI [10.1109/TMI.2024.3435015](https://doi.org/10.1109/TMI.2024.3435015)。[官方仓库](https://github.com/philip-mueller/wsrpn)与[MIT许可](https://github.com/philip-mueller/wsrpn/blob/main/LICENSE)公开，作者说明只需图像级标签训练ROI proposal/attention，不强制要求额外框标注；不能因当前没有框就笼统说不能适配。[出版与摘要](https://pubmed.ncbi.nlm.nih.gov/39073999/)可交叉核查。

其目标偏弱监督病灶定位，原实现默认会准备或下载外部CXR8数据，并带专用ROI头、损失及训练配置，不能直接执行默认train.py就满足本赛。若后续使用，应换为合规ImageNet初始化，完全接入官方10类训练数据与Study评估，禁止外部医学权重/数据自动下载。这属于需要额外实现和验证的结构适配，当前列作未试备选，不写成已经跑失败，也不声称其定位优势必然提高本题AUC。
