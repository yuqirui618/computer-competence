# MambaOut 优化代码快照

这里保存本地实际执行过的优化代码，包括保护性微调与 ASL、Dropout/DropPath、稀有类加权、光照/MixUp、Gamma/轻噪声、患者分组 F1 阈值校准、双模型概率平均和权重复核。`sources/` 中的文件按原 E 盘相对路径归档，内容与来源文件逐字一致；`source_manifest.json` 记录归档路径、原相对路径和 SHA256。

这是一份历史实验源代码包。脚本保留当时的固定路径、数据规模、权重 SHA 和历史产物断言，克隆仓库后还需要原本地环境与实验文件，不能直接从仓库开始复现全部结果。

| 路径 | 用途 |
| --- | --- |
| `sources/` | 按原中文目录拓扑保存的实际实验代码与依赖 |
| `source_manifest.json` | 来源路径和逐文件 SHA256；部署工具据此校验 |
| `deploy_sources.py` | 仅校验或部署源文件；默认只读检查 |
| `reports/总结.md` | 最新六轮全量增强结果、F1 与增强的证据及局限 |
| `reports/六轮明细.csv` | 三组各两轮的聚合指标，不包含逐样本预测 |

ASL 改写代码的上游来源与 MIT 许可随快照一并保存；使用时保留对应 `LICENSE.ASL.txt` 和来源说明。算法和原实验配置没有因本次归档而更改。

## 在本机使用

本包目前只支持原有 Windows 路径 `E:\比赛数据集`。部署工具不会更改源文件中的冻结路径，也不安装环境、下载模型或开始训练。原环境为 `E:\比赛数据集\envs\cxr-smoke-cu128`，依赖版本沿用 [model01/requirements.txt](../requirements.txt)。

从仓库根目录打开 PowerShell，先执行默认只读检查：

```powershell
$python = 'E:\比赛数据集\envs\cxr-smoke-cu128\Scripts\python.exe'
& $python -B model01\optimization\deploy_sources.py --data-root 'E:\比赛数据集'
```

工具先检查全部归档源文件的 SHA256、目标目录和现有文件，列出将复制与已相同的项目。**默认命令不写文件。** 只有需要补齐本地缺失的源文件时，才显式加入 `--apply`：

```powershell
& $python -B model01\optimization\deploy_sources.py --data-root 'E:\比赛数据集' --apply
```

已存在且 SHA 相同的文件会跳过；任何不同文件、归档校验失败、路径越界或软链接/重解析点都会拒绝。全部文件预检通过后才开始补齐，工具不覆盖现有不同文件。复制过程的临时文件只在对应 E 盘目标目录生成并清理。它仅处理清单中的代码、配置、说明与许可文件，不部署权重、图像、CSV 数据或 NPZ 预测。

## 运行优化前需要的本地产物

根据要运行的历史脚本，至少需要准备相应的下列项目：

- 官方数据、原有 `喻数据产物/manifest.csv`、512 缓存和 `本地跑通/data_local.yaml`，以及脚本要求的类别表和预训练模型来源元数据。
- `本地跑通/pretrain_model/model.safetensors` 等合法取得的预训练权重。
- 保留的原最佳 `MambaOut_ASL对照/best_model.pth`、对应 gates，以及其他脚本要求的历史逐轮 checkpoint。部分脚本同时核对原 submission 的 SHA。
- 阈值与概率平均实验使用的历史 NPZ、既有结果 JSON、相应患者分组信息；这些本地产物没有包含在代码包中。

源代码里的断言用于复核当时实验，不是自动下载机制。缺少某个输入时，应先按脚本核实依赖；不要删除 SHA、患者隔离或指标复现检查来强行运行。

**请从部署后的 E 盘实验目录执行经过核对的脚本。不要直接运行或导入仓库 `sources/` 中的历史脚本。** 其中一些文件会在导入时创建本目录的 `temp`、设置缓存或隐藏 GPU；`verify_f1_candidate.py` 等历史验证脚本还会在导入时执行 GPU 验证。将它们当成普通库导入，可能启动计算或把缓存写在仓库所在盘。F1 阈值任务应使用单独 CPU 进程，GPU 训练与验证按顺序执行。

部署命令仅整理代码，**不会重跑实验**。实际开始某项历史实验前，需要阅读该脚本、确认原产物齐全和输出位置；训练/验证可能继续写入对应 E 盘实验目录。

## 如何看待已有结果

以 `reports/总结.md` 和六轮明细为准。最新 Gamma 加轻噪声候选取得更高的 AUC 点估计，但 F1 没有同步改善，患者重采样的差异区间仍包含零。F1 阈值调优、已有增强和原长程训练的结论均有验证集重复使用、单种子、患者数量及训练预算的限制，不能据此宣布算法已达到上限。

本包归档当前已完成的优化；后续新模型实验另行组织。
